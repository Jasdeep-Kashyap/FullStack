Goal
Make an application that will analyse the given data and provide info about trucks


Tech Stack

Build & Bundler => Vite  
                    ??Instant HMR, zero-overhead build times, native ES modules.
Frontend Framework	=> React + TypeScript	
                    ?? Industry-standard reliability, strict end-to-end type safety, large ecosystem.

Styling & UI Primitives	=> Tailwind CSS + shadcn/ui	
                        ?? Accessible, copy-paste components built on Radix primitives; looks modern instantly with zero runtime CSS overhead.

Linter => ESLint

Backend & API => Fastify (Node.js/TS) or FastAPI (Python)	
              ?? High throughput, minimal boilerplate, automatic schema validation and auto-generated API docs.

Database & ORM => PostgreSQL+ Drizzle ORM	
               ?? ACID compliant, SQL-like type safety, zero bloat compared to heavier ORMs like Prisma/TypeORM.

Client State / Data => TanStack Query (React Query)	
                    ?? Handles caching, deduplication, and loading/error states out of the box.

Tech Stack -beginner friendly,lighweight,easy to learn and use
